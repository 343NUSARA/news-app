# 📰 Alfa Vision - Dynamic News Portal

Alfa Vision is a responsive news web application that delivers real-time news from multiple categories using the GNews API. The application provides an intuitive and engaging user experience with category filtering, keyword-based search, and smooth animations.

## 🚀 Features

- 🌍 Real-time news using GNews API
- 🔍 Search news by keywords
- 📂 Browse news by categories
- 📱 Fully responsive design
- ✨ Smooth GSAP animations
- 🖼️ Modern and clean UI
- ⚡ Fast loading with optimized API calls
- 📄 Dynamic rendering of news articles

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (ES6+)
- GNews API
- GSAP (GreenSock Animation Platform)

## 💻 Tools Used

- Visual Studio Code
- Git & GitHub
- Chrome DevTools


## ⚙️ How to Run

1. Clone the repository

```bash
git clone https://github.com/343NUSARA/news-app.git
```

2. Open the project folder.

3. Add your GNews API key in the JavaScript configuration file.

4. Open `index.html` in your browser.
